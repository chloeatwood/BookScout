# 📚 BookScout

BookScout is a full-stack book discovery, tracking, and price comparison
application that I am currently developing.

The goal is to combine traditional software engineering with data engineering
and machine learning to create a personalized book discovery platform.

## 🚧 Current Status

**In active development**

- [ ] Price data collection
- [ ] Price analysis
- [ ] Price prediction
- [ ] Cloud deployment

## 🧠 ML & Data Goals

BookScout is also being used as a project for learning machine learning and
data engineering.

Planned ML/data components include:

- Content-based book recommendations
- NLP and text embeddings
- Book similarity using vector representations
- Price data collection and ETL
- Historical price analysis
- Book price prediction
- Book/edition entity matching
